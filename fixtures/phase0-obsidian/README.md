# Phase 0 Obsidian fixture

這是一組 synthetic、人工製作的 fixture，用來驗證 KGnote v0 Markdown/YAML contract，
不是 learner 的真實學習紀錄。

在 Obsidian 以本目錄作為 vault 開啟後，從
[[concepts/concept_correlation|Correlation]] 開始。預期可在第一次點選抵達
[[evidence/evidence_question_correlation_causation|提問 evidence]]，第二次點選抵達
[[sources/src_synthetic_causality_chat|完整 synthetic source]]。

`raw/synthetic-causality-chat.md` 是 Source record 所登記的 immutable content；canonical
notes 不得覆寫它。`edges/` 保存 typed relation，正文 links 只負責 Obsidian 導覽。
