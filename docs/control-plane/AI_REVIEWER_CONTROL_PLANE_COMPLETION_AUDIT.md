## Evidence interpretation boundary

Local verification proves deterministic control-plane behavior for one exact worktree candidate. It does not prove product semantics, reviewer independence, cryptographic actor identity, physical-device behavior, human acceptance, live-provider behavior, or release readiness. Reviewer identity is policy- and audit-enforced unless repository permissions or signed changes are separately configured.

The goal is not semantically complete until a separate independent reviewer context submits a valid fingerprint-matched result for the sealed RP-4 candidate. The reviewer bootstrap explicitly says it is the required reviewer and must act now, not defer to ChatGPT Work. Any PASS remains subordinate to explicit KGnote human gates.
