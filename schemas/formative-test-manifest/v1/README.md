# Formative test manifest v1

這個 contract 固定一場小型 formative test 的 Source revision、pretest、兩個條件、任務、
rubric、主要指標、排除／中止條件與 `continue | modify | stop` 規則。它不是通用 analytics
平台，也不把 N=1 結果包裝成因果或群體效果。

`run-record` 只記錄本次介面可觀察事件與使用者明確提供的回答。planned template 可保留
`pretest: null`、空 observations 與 `decision: null`；實際紀錄放在 ignored `output/`，不把私人
學習文字加入 repository。
